# R examples

## Requirements

* `iceR`: This is an R package that we've bundled for you which you can install using devtools. In R you can run the following (if you get any compilation errors, check the package installation instructions [here](https://github.com/Icepack-co/iceR).
```
devtools::install_github("icepack-co/iceR")
```

* [Quarto](https://quarto.org/docs/download/): The examples have been put together in a user-friendly format to run things step by step and visualise the output using the sample data provided. 


## Getting going

Once Quarto is installed, run the following in the command line from within the R directory (and the example will open in the browser):

```
quarto preview <NAME_OF_QMD_FILE.qmd>
```
